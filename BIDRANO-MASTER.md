# Bidrano Master UI System

## Product direction
AI-native content production studio, not a chatbot.

## Visual language
Warm editorial SaaS: cream surfaces, dark espresso navigation, restrained orange accent, muted gold details, generous whitespace, strong hierarchy.

## UX principles
- Persian RTL first.
- Progressive disclosure.
- One primary action per screen.
- Human approval before production.
- Granular regeneration.
- Approved outputs become Brand Memory.
- Calendar is planning, not production permission.
- QA is visible as a pipeline stage.

## Core states
Draft → Ready to Start → Producing → QA → Ready for Review → Revision → Approved → Exported.

## Typography
Vazirmatn, 400/500/600/700/800.

## Accessibility
Visible focus states, semantic controls, adequate contrast, keyboard-friendly navigation, no color-only status communication.
