# بازبینی کد Bidrano

تاریخ: ۲۱ مهر ۱۴۰۵ / ۱۳ اکتبر ۲۰۲۶

## دامنه بررسی

دو دور بازبینی فایل‌های منبع انجام شد: دور اول، جریان داده و رفتار هر صفحه؛ دور دوم، تطبیق صفحه‌ها با مدل‌ها، ذخیره‌سازی و قرارداد API. کدهای تولیدشده، node_modules و باینری تصویر و فونت به عنوان کد پروژه بازنویسی نشدند. قفل وابستگی‌ها به صورت ساختاری بررسی شد و تصویر و فونت در مرورگر بارگذاری شدند.

## نتیجه بررسی‌ها

- بررسی TypeScript بدون تولید خروجی موفق شد.
- ۱۳ تست خودکار برای اعتبارسنجی، rollback، انتقال، ذخیره همزمان، ثبت یکتا، خطاهای HTTP و محدودیت بدنه موفق شدند.
- ۱۲ صفحه در عرض‌های ۱۴۴۰، ۳۹۰ و ۳۲۰ پیکسل بررسی شدند؛ سرریز افقی و خطای JavaScript مشاهده نشد.
- تعویض مشتری پس از انتخاب پیشنهاد، شکست ذخیره سفارش، جابه‌جایی سفارش با query و داده خراب جزئیات در مرورگر بررسی شدند.
- درصد پیشرفت بدون سفارش فعال و با سفارش فعال و همچنین ترتیب محتوای اخیر در مرورگر بررسی شدند.
- تست‌های فایل در پوشه موقت جدا انجام شدند و داده واقعی مشتری‌ها تغییر نکرد.
- بیلد انتشار اجرا نشد. بررسی مرورگر در حالت توسعه انجام شد.

## محدودیت‌های واقعی باقی‌مانده

- سفارش و تولید هنوز نمونه محلی‌اند؛ پژوهش، تولید هوش مصنوعی و خروجی واقعی API ندارند.
- ذخیره مشتری فایل محلی با یک فرایند سرور است؛ احراز هویت، مالکیت داده و دیتابیس انتشار عمومی هنوز پیاده‌سازی نشده‌اند.
- بازگرداندن localStorage در شکست، best-effort است؛ اگر خود مرورگر تمام عملیات نوشتن را مسدود کند، تضمین تراکنش دیتابیس ندارد.
- مرورگر و تست‌ها تضمین نبودن همه خطاهای آینده یا آماده‌بودن برای استقرار عمومی نیستند.
